# Проект «Готово.» — Умный кулинарный AI-ассистент

Проект разработан для хакатона **Ilmhona × MLH** (тема: *AI for Everyday Life*).
«Готово.» помогает пользователю решить, что приготовить из имеющихся дома продуктов с помощью мультимодального искусственного интеллекта Gemini.

## Архитектура и технологии
- **Фронтенд:** React 19, TypeScript, Tailwind CSS v4, Motion, Lucide Icons, Canvas-Confetti.
- **Бэкенд:** Node.js, Express, WebSocket (Live streaming), `@google/genai` (Gemini 3.6 Flash, Gemini Live Vision, Gemini Audio TTS).
- **Стилизация и дизайн:** Минималистичная бело-голубая палитра (`#F0F4F8`, `#0F172A`), акцентный томатно-красный (`#E4572E`), шрифты *Space Grotesk* (заголовки), *Inter* (текст), *IBM Plex Mono* (значения и таймеры), стиль магнитов на холодильнике.
- **Мобильная версия (Android / iOS / Expo / PWA):** Адаптивный мобильный интерфейс, нижняя панель навигации для телефонов, поддержка переключения камер смартфона, синтез речи Web Speech API и Gemini TTS, а также готовый React Native / Expo проект в директории `/mobile` с `expo-image-picker`, `expo-speech` и `expo-haptics`.

## 5 ключевых возможностей
1. **Мультимодальное распознавание продуктов по фото (Gemini Vision):**
   - Загрузка фото или снимок камеры холодильника.
   - Автоматическое извлечение названий продуктов, ориентировочного веса и уверенности.
2. **Умная фильтрация по категориям (Магнитики холодильника):**
   - Выбор типов блюд (Завтраки, Супы, Салаты, Основные блюда, Десерты, Выпечка).
   - Каждое сгенерированное блюдо строго привязано к выбранным категориям.
3. **Генерация 2–4 разнообразных вариантов блюд:**
   - Не один рецепт, а несколько сбалансированных опций с калорийностью, временем приготовления, БЖУ и секретами шефа.
4. **Голосовое управление и чтение рецептов (Speech-to-Text & Text-to-Speech):**
   - Диктовка продуктов голосом через микрофон.
   - Озвучивание пошагового рецепта вслух.
5. **Live-Шеф видео-сопровождение (Gemini Live):**
   - Режим прямого наблюдения за сковородой/доской через камеру.
   - Голосовые подсказки в реальном времени, оценка степени прожарки, таймеры шагов и предупреждения о безопасности.

## Правила разработки и конвенции
- Всегда соблюдать типизацию в `src/types/index.ts`.
- API-ключи хранить исключительно на сервере (`process.env.GEMINI_API_KEY`), никогда не передавать в браузер.
- Обеспечивать поддержку мобильных экранов с тач-зонами от 44px.
