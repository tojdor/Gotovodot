# 📱 Мобильное приложение «Готово.» для Expo Go (Android & iOS)

Приложение разработано для хакатона **Ilmhona × MLH** и позволяет управлять умным кулинарным ассистентом прямо со смартфона через **Expo** и **React Native**.

---

## 🚀 Быстрый запуск на телефоне через Expo Go

### Шаг 1: Установите приложение Expo Go на телефон
- **Android:** Скачайте [Expo Go в Google Play](https://play.google.com/store/apps/details?id=host.exp.exponent)
- **iOS:** Скачайте [Expo Go в App Store](https://apps.apple.com/app/expo-go/id982107779)

### Шаг 2: Установка зависимостей мобильного клиента
Откройте терминал в папке `mobile`:
```bash
cd mobile
npm install
```

### Шаг 3: Запуск сервера разработки с туннелем
```bash
# Рекомендуемый запуск с глобальным туннелем (работает в любой сети и через мобильный интернет):
npx expo start --tunnel

# Или стандартный запуск в локальной Wi-Fi сети:
npx expo start
```

### Шаг 4: Открытие на телефоне
1. Откройте камеру на телефоне (или приложение **Expo Go** на Android).
2. Наведите объектив на **QR-код** в терминале или в модальном окне веб-интерфейса «Готово.».
3. Нажмите появившуюся ссылку — приложение откроется в Expo Go!

## ⚙️ Возможности мобильного приложения
1. **📸 Мультимодальный анализ холодильника:** Фотографируйте полки камерой телефона или выбирайте фото из галереи (`expo-image-picker`), Gemini Vision моментально находит продукты.
2. **🧲 Интерактивные магниты категорий:** Завтраки, Супы, Салаты, Основные блюда, Десерты, Выпечка.
3. **✨ Генерация 2–4 рецептов:** Сбалансированные рецепты с временем, калориями, БЖУ и ингредиентами.
4. **🔊 Голосовой шеф (Text-to-Speech):** Пошаговая озвучка шагов приготовления вслух через `expo-speech`.
5. **📳 Тактильный отклик (Haptics):** Вибрации смартфона при завершении таймеров и нажатии кнопок (`expo-haptics`).
6. **🌐 Настройка адреса сервера:** Возможность указать удаленный адрес Cloud Run или локальный `http://192.168.x.x:3000`.
